CalaSign· Claude Code

Plugin de CalaSign para Claude Code

Servidor MCP remoto, la skill calasign y los comandos /calasign:send y /calasign:status.

Instalar

claude plugin marketplace add {{BASE_URL}}/integrations/claude-code/marketplace.json
claude plugin install calasign@calasign

O dentro de Claude Code: /plugin marketplace add {{BASE_URL}}/integrations/claude-code/marketplace.json y después /plugin install calasign@calasign.

Conectá tu cuenta: /mcp → calasign → Authenticate (se abre CalaSign para autorizar).

Requiere Claude Code 2.1.224 o posterior (plugins con fuente archive). Archivos: marketplace.json · calasign-plugin-{{VERSION}}.zip

Usar

/calasign:send contratos/servicios.pdf Ana Pérez ana@cliente.com
/calasign:status ACME

Claude siempre muestra un resumen y pide confirmación antes de enviar o anular.

Solo el servidor MCP (sin plugin)

claude mcp add --transport http calasign {{BASE_URL}}/mcp
# con API key en lugar de OAuth:
claude mcp add --transport http calasign {{BASE_URL}}/mcp --header "Authorization: Bearer $CALASIGN_API_KEY"
