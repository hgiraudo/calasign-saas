CalaSign· Word y Outlook

Complemento de CalaSign para Word y Outlook

Word: enviá a firmar el documento abierto. Outlook: enviá a firmar un PDF adjunto del correo, con el remitente como firmante.

manifest.xml (Word)manifest-outlook.xml (Outlook)

Word en Windows o Mac

  1. Descargá manifest.xml.
  2. Windows: compartí una carpeta de red con el manifiesto y agregala en Archivo → Opciones → Centro de confianza → Catálogos de complementos de confianza; después Inicio → Complementos → Mis complementos → Carpeta compartida.
    Mac: copiá el archivo a ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/ y reabrí Word.
  3. En Inicio aparece Enviar a firmar.

Word en la web

  1. Inicio → Complementos → Más configuraciones → Cargar mi complemento → elegí manifest.xml.
  2. Word en la web no exporta a PDF desde un complemento: elegí el PDF desde tu equipo.

Outlook (nuevo, clásico y web)

  1. Abrí aka.ms/olksideload → Mis complementos → Complementos personalizados → Agregar desde archivo → manifest-outlook.xml.
  2. Abrí un correo con un PDF adjunto → Enviar adjunto a firmar.

Administradores de Microsoft 365

Centro de administración → Configuración → Aplicaciones integradas → Cargar aplicaciones personalizadas → subí cada manifiesto para desplegarlo a la organización.

La primera vez, el complemento pide iniciar sesión en CalaSign (OAuth). Si la ventana no abre, se puede usar una API key.
