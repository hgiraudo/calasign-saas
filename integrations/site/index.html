Integraciones

Firmá documentos desde tu asistente de IA o desde Office. Servidor MCP: {{BASE_URL}}/mcp (OAuth o API key).

Claude (claude.ai y Claude Desktop) — conector

  1. Ajustes → Conectores → Agregar conector personalizado.
  2. URL: {{BASE_URL}}/mcp → Agregar → Conectar e iniciá sesión en CalaSign.

Skill opcional (enseña a Claude a usar CalaSign con cuidado): calasign-skill.zip → subila en claude.ai/customize/skills (requiere ejecución de código habilitada).

Claude Desktop — extensión (.mcpb)

Descargar calasign.mcpb

Abrila con doble clic (o Ajustes → Extensiones → Instalar extensión) y pegá tu API key de CalaSign (Ajustes → API keys).

Claude Code — plugin

claude plugin marketplace add {{BASE_URL}}/integrations/claude-code/marketplace.json
claude plugin install calasign@calasign

Después, en Claude Code: /mcp → calasign → autenticar. Comandos: /calasign:send, /calasign:status. Más detalles.

Solo el servidor MCP: claude mcp add --transport http calasign {{BASE_URL}}/mcp

ChatGPT

Agregá un servidor MCP personalizado (modo desarrollador) con la URL {{BASE_URL}}/mcp y autenticación OAuth. Guía paso a paso y ejemplo de la API de OpenAI.

Gemini CLI

gemini mcp add --transport http calasign {{BASE_URL}}/mcp

O la extensión con contexto: calasign-gemini-extension.zip

unzip calasign-gemini-extension.zip -d calasign && gemini extensions install ./calasign

En Gemini: /mcp auth calasign. API de Gemini (Python): example.py.
